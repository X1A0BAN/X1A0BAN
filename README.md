## Featured Projects

### [A 股多 Agent 投资辅助系统](https://github.com/X1A0BAN/Ai-trading-Agents)

基于 **LangGraph + FastAPI** 的 A 股投资辅助系统，独立设计与开发。

- 设计 11 个逻辑 Agent，覆盖信息研究、基本面分析、量化分析、反方审查、预案构建与风险审核
- 使用确定性状态机管理交易日历、复权行情、仓位、止损止盈与风险硬限制
- 使用 Pydantic Schema 约束 Agent 输入输出，支持 SSE 实时进度推送与长任务断点恢复
- 通过 Prompt 版本化和 `agents.yaml` 配置实现角色、工具和重试策略管理

### [Cognitive Arena 认知竞技场](https://github.com/LuYiwen007/hackAstone)

一个通过多 Agent 辩论、圆桌讨论和思维画像帮助用户探索观点的 AI 产品。3 人团队项目，我负责后端接口与 Web 界面设计。

- 基于 **Spring Boot + MyBatis** 搭建 REST 接口与统一 Agent 代理层
- 接入阿里云百炼平台的 6 个 AI Agent，设计超时控制与短期缓存机制
- 基于 **React + TypeScript + Vite** 实现思想家世界地图、哲学辩论、圆桌讨论和思维画像页面
- 项目入围 **hackAstone 全球黑客松总决赛**

### [A 股个股分析数据看板](https://github.com/X1A0BAN/securities_platform)

基于 **Python + MySQL + FineBI** 的个股行情数据分析项目，负责 FineBI 看板的主要设计与实现。

- 使用 Python 和 Tushare Pro 采集沪深主板行情数据及复权因子，并写入 MySQL
- 支持历史数据回补与每日增量同步
- 使用 FineBI 构建个股与大盘走势、市场分位、涨跌分布、量价结构和日内振幅分析
- 完成“数据采集 → 数据入库 → 可视化 → 分析结论”的完整闭环
